# Кумовья: Большая семейка

![Кумовья — семейно-экономический кликкер](public/og.png)

> Семья — это святое. Особенно когда всё записано на неё.

Семейно-экономический кликкер с чёрным юмором: дави на связи, собирай команду, разруливай кипиш и строй империю сомнительных знакомств. Персонажи и ситуации — художественная сатира.

## Что внутри

- Семь персонажей с собственными способностями и сгенерированными иллюстрациями, включая адского решалу и Бабу Ягу.
- Семь сюжетных глав, 21 большой этап и постоянные бонусы за решения семьи.
- Три иллюстрированных района: гаражи, ночной рынок и районная управа.
- Десять мутных дел с командой, фиксированной наградой и разными условиями.
- Пятнадцать событий с явным выбором между тихим решением и показухой.
- Палево: шумные решения рискованнее, а спокойные постепенно охлаждают район.
- Семь личных историй — по одной для каждого героя.
- Шесть улучшений: от огурцов без паспорта до кота-крыши, с усилением каждых пяти покупок.
- Пассивный доход и рост от случайного гостя до легенды семейного чата.
- Управление касанием, мышью или клавиатурой; переключаемый звук.
- Мобильная вёрстка и подготовка к запуску в Telegram.

## Семейный состав

| Персонаж | Роль | Особенность | Открывается при |
| --- | --- | --- | --- |
| Кум Валера | Решала у мангала | Усиленные клики | Сразу |
| Кума Виктория | Тамада судного дня | Каждый 12-й клик ×8 | 150 авторитета |
| Тётя Сара | Админ семейного чата | Пассивный доход +45%, события чаще | 600 авторитета |
| Гопон Миша | Авторитет на корточках | «Ты меня уважаешь?» — улучшения дешевле на 20% | 2 200 авторитета |
| Тётя Зина | Нотариус последней надежды | Бонусы событий ×2,5 | 9 000 авторитета |
| Кум Азазель | Адский решала | Тычки +40%; при палеве от 70 — ещё ×1,5 | После главы 4 |
| Баба Яга | Председатель ТСЖ «Избушка» | Доход +60%, охлаждение палева в пять раз быстрее | После главы 5 |

Первые пять персонажей открываются по общему заработанному авторитету: покупки не отодвигают их открытие. Двое потусторонних родственников присоединяются после завершения соответствующих сюжетных глав.

Миша занимает прежний четвёртый слот: старые сохранения, покупки и открытые персонажи остаются на месте.

## Район решает

Новая глава строится вокруг цикла **выбрать дело → собрать команду → выполнить условие → решить кипиш → забрать награду**.

- Ночной рынок открывается при 1 200 общего авторитета и двух разных закрытых делах.
- Районная управа открывается при 6 000 общего авторитета и шести разных закрытых делах.
- Специалист по делу даёт +25% к награде, а второй герой в команде — ещё +10%.
- С 70 палева новые дела дают на 20% меньше; тихое решение события снимает 12 палева, показуха добавляет 18.
- Повторное дело даёт 35% базовой награды; его условия постепенно растут, денежные цели также учитывают текущий доход. Покупки всегда считаются заново.
- Два поручения или сюжетных этапа с героем в команде открывают его личную историю и разовую награду.

Награда, цель и состав фиксируются при старте: последующая смена персонажа не меняет уже взятое дело. Пассивный доход работает, пока страница игры открыта; отдельного офлайн-начисления нет.

## Большая семейка

Кампания рассчитана ориентировочно на неделю коротких заходов по 20–30 минут. Модель прохождения даёт около 2,5–3 часов активной игры при развитии хозяйства; это ориентир, а не результат пользовательского плейтеста. Старые богатые сохранения и оптимальная тактика могут пройти её быстрее. Календарных замков и принудительного ожидания следующего дня нет.

1. Клятва на капоте.
2. Крыша без потолка.
3. Похороны конкуренции.
4. Аренда у преисподней — присоединяется Азазель.
5. Прописка на курьих ножках — присоединяется Яга.
6. Выборы до Страшного суда.
7. Конец света по-семейному.

В каждой главе три этапа: заработок, развитие хозяйства, поручения, тихие или шумные решения. Некоторым этапам нужна определённая команда и подходящий уровень палева. Все цели начинают считаться только после старта этапа. Обычные поручения можно выполнять параллельно.

Вклад в район списывается только при сдаче этапа, а не при старте; отмена сбрасывает только его текущие счётчики. Для старта и сдачи нужен район главы, но в процессе можно путешествовать. Закреплённый состав определяет ответственных и отношения, а героя для кликов разрешено менять.

В финале каждой главы можно навсегда добавить +5% к доходу или +5% к тычку. Бонусы складываются без сброса имущества. Каждые пять экземпляров одного улучшения добавляют +50% к эффекту всех экземпляров этого улучшения.

Telegram-бот для подключения: [@kumavya_bot](https://t.me/kumavya_bot).

## Запуск

Требуется Node.js 22.13+.

```sh
npm ci
npm run dev
```

Сборка для GitHub Pages с проверкой картинок и адресов:

```sh
npm run build:github
```

Готовый статический сайт находится в `out/`. Команда работает в Windows, macOS и Linux, не требует токенов и не отправляет файлы во внешние сервисы. Проверку готовой папки можно повторить через `npm run verify:github`.

Локальная разработка сохраняет Vinext/Vite; публикация на GitHub Pages использует статический экспорт установленного Next.js. Исходная сборка `npm run build` сохранена, но для GitHub Pages не используется. Проверка типов: `npx tsc --noEmit`.

## Публикация на GitHub Pages

1. Для GitHub Free репозиторий должен быть публичным.
2. В репозитории откройте **Settings → Pages** и выберите **Source: GitHub Actions**.
3. В **Actions** запустите **Publish Kumovya to GitHub Pages → Run workflow** либо отправьте изменения в `main`.
4. Дождитесь зелёного результата задания `deploy`.

Workflow публикует только готовую папку `out/`, без исходных фото, служебных настроек и секретов. При последующих изменениях сборка, проверка файлов и публикация выполняются автоматически. OpenAI Sites для этого способа не используется.

## Telegram Mini App

Игра подключает официальный Telegram SDK, сообщает о готовности, раскрывает окно и учитывает безопасные отступы. Она также работает в обычном браузере. Никакой токен бота во frontend не требуется.

1. Дождитесь успешной публикации и проверьте адрес `https://assaboud-commits.github.io/kumovya-clicker/`. Адрес репозитория GitHub для запуска приложения не подходит.
2. В [BotFather](https://t.me/BotFather) отправьте `/mybots`, выберите **@kumavya_bot**, включите **Main Mini App** в настройках и укажите адрес игры.
3. Через `/setmenubutton` выберите **@kumavya_bot**, добавьте кнопку **Играть** с тем же адресом.
4. После настройки Main Mini App прямая ссылка запуска: `https://t.me/kumavya_bot?startapp`.

[Официальная инструкция Telegram](https://core.telegram.org/bots/webapps#launching-the-main-mini-app).

## Сохранения и безопасность

- Прогресс хранится только в localStorage этого браузера/устройства, без синхронизации между устройствами и аккаунтами.
- Сохранения v1 и v2 читаются автоматически и переносятся в v3: авторитет, покупки, персонажи, пройденные поручения и истории сохраняются. Исходные записи не удаляются.
- Активные поручение и сюжетный этап, зафиксированные команды, цели, награда, палево и неразрешённый кипиш также сохраняются.
- Если устройство блокирует сохранения, игра предупреждает об этом и продолжает работу до закрытия окна.
- Токены ботов, ключи, исходные фотографии, `.env` и личные данные не следует добавлять в GitHub.
- В репозитории находятся только готовые игровые иллюстрации, без исходных фотографий.
- Серверных рейтингов, платежей и проверки аккаунтов пока нет. Для них требуется отдельная серверная реализация с проверкой Telegram `initData`.
